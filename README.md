## Project Goal
Deliver an actionable scouting-style report that pairs **Called Strikes + Whiffs (CSW%)** with **On-base Plus Slugging (OPS)** to spotlight:

- Which pitchers reliably create strikes via command vs. stuff.
- Which pitch types deserve more or less usage based on performance and opportunity.
- How hitters balanced swing decisions, contact skills, and run production in a short sample.

The analysis is driven from the `Player's_Performance.ipynb` notebook and the `AnalyticsQuestionnairePitchData.csv` pitch-level dataset (620 pitches, 67 columns).

## Methodology
The notebook proceeds in a classic analytics workflow:

### Data Quality Assessment
- Configured pandas display settings and executed `.info()` to inspect column types and non-null counts.
- Visualized missingness with a seaborn heatmap and tabulated missing rates to confirm that identity/outcome fields were complete while kinematic fields carried ~3% nulls.
- Documented a retention plan to keep all rows because the analysis relies on event-level rates rather than continuous trajectories.

### Feature Engineering
- Mapped `PitchCall` outcomes into logical groups (hits, balls in play, swinging strikes, called strikes, walks, strikeouts, terminal events).
- Added binary indicator columns such as `is_hit`, `is_ball`, `is_called_strike`, and pitch-specific hit flags (`hit_single`, `hit_double`, etc.).
- Classified swings to calculate Swing%, Whiff/Swing%, Balls%, CSW%, and BIP% at the pitcher level.
- Prepared batter-level measures for plate appearances, OBP, SLG, OPS, Swing%, Contact%, and Whiff/Swing%.

### Aggregations & Exported Tables
- Summarized top-level distributions for `PitchCall`, `PitchType`, counts, and handedness to profile the sample.
- Produced grouped tables: `pitcher_summary.csv`, `batters_summary.csv`, `top_pitchers_csw.png`, and `top_batters_ops_with_approach_table.png` to highlight leaders.
- Built opportunity analyses (`mix_quality_opportunity*.csv`) combining pitch-type usage with CSW effectiveness to flag under/over-used offerings.
- Saved formatted tables for presentation-ready reporting.

## Key Findings
- **Strike Creation:** P6’s knuckle-curve and P11’s changeup are elite CSW pitches with capacity to scale; several sinkers and the P15 fastball underperform and should be trimmed or reshaped.
- **Usage Recommendations:** Increase P11–CH (+5–10 share points), P1–SL (+5–8), P6–KC (+5–8), P7–CU/FC (+4–6) while holding or reducing low-CSW four-seams for P14 and P15.
- **Hitter Profiles:** OPS leaders paired aggressive swings with manageable whiff rates, and the approach map clarifies who combines volume (plate appearances) with quality contact.
- **Data Health:** Operational data columns are complete, enabling confident calculation of discrete-event metrics despite minor trajectory gaps.

## How to Reproduce
1. **Environment**
   - Python 3.9+
   - Libraries: `pandas`, `numpy`, `seaborn`, `matplotlib`, `scipy`
2. **Open the notebook**
   ```bash
   jupyter notebook "Player's_Performance.ipynb"
   ```
3. **Run all cells** to regenerate tables and figures. Outputs are saved alongside the notebook via `matplotlib.pyplot.savefig` calls.
4. **Review exported assets** in the repository root or share them directly with stakeholders.

> _Note:_ Online execution environments may require manual installation of the dependencies listed above.
